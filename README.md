# Power BI – Sales & Revenue Analysis Dashboard

An interactive Business Intelligence project developed using Microsoft Power BI to analyze sales performance, revenue trends, product performance, discounts, returns, and customer data.

## Project Overview

This project transforms sales data into meaningful business insights using data preparation, data modeling, DAX calculations, and interactive visualizations.

The report contains five pages covering different aspects of business performance.

## Dashboard Pages

1. **Home** – Main dashboard navigation.
2. **Sales Overview** – Sales performance analysis.
3. **Revenue and Discounts** – Revenue trends and discount analysis.
4. **Sales by Product** – Product-level sales analysis.
5. **Returns and Customers** – Return patterns and customer analysis.

## Tools and Technologies
